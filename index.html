Cuidados del arroz

Almacenamiento
  • Guarda el dispensador en un lugar fresco, seco y sin luz directa del sol.
  • Mantén la tapa bien cerrada; el sello evita humedad e insectos.
  • Coloca 1 o 2 sobres de gel de sílice (desecante de grado alimenticio) en la tapa.
  • Una hoja de laurel seca dentro del depósito ayuda a repeler gorgojos.
  • Arroz blanco: hasta 1–2 años bien guardado. Integral: 6 meses (tiene aceites que se enrancian).
Señales de que el arroz ya no está bien
  • Olor rancio, a humedad o agrio.
  • Granos pegados en grumos, manchas verdes, negras o amarillas.
  • Insectos, telarañas finas o granos con agujeros.
  • Si ves moho, desecha todo el contenido y limpia el depósito.
Al rellenar
  • No mezcles arroz nuevo con el viejo: termina primero el anterior o sácalo y ponlo arriba.
  • Revisa que el depósito esté completamente seco antes de llenar.
  • Presiona «Acabo de rellenar» en esta pantalla para llevar la cuenta de días.
Arroz ya cocido
  • Refrigéralo en menos de 1 hora después de cocinarlo.
  • Consúmelo en 3–4 días y recaliéntalo una sola vez, hasta que humee.

Instrucciones

Todo lo necesario: uso de la página, armado, configuración de Blynk, código y mantenimiento.

1 · Cómo usar esta página

1Registro inicial. La primera vez se te piden tus datos (nombre, edad, género, peso, estatura, actividad, objetivo y tipo de arroz). Con ellos se calcula tu porción y tus calorías. Puedes editarlos en Ajustes.

2Conectar con Blynk. En Ajustes pega el Auth Token de tu dispositivo y el servidor (normalmente blynk.cloud). Sin token la página funciona en modo demo con datos simulados.

3Panel. Ves el nivel de arroz (sensor ultrasónico), la humedad y la temperatura (sensor DHT22) y el estado del arroz. Se actualiza cada 5 segundos.

4Servir. Ajusta los gramos por persona y el número de personas y toca Dispensar ahora. La página manda el total a Blynk (V0) y activa el dispensador (V1).

5Calorías. Consulta tu meta diaria y la porción de arroz recomendada para desayuno, comida, cena y colación.

6Recetario. Filtra por tiempo de comida y objetivo. Cada receta trae su cantidad de arroz ajustada a ti y un botón para servirla.

7Cuidado. Revisa el estado del arroz y marca cuando rellenes el dispensador.

Para que la conexión real con Blynk funcione, abre el archivo dispensador-arroz.html en el navegador de tu computadora o celular, o súbelo a un hosting (Netlify, GitHub Pages). La vista previa de Claude bloquea conexiones externas y solo muestra el modo demo.
2 · Materiales
  • ESP32 (DevKit v1) + cable USB
  • Sensor ultrasónico HC-SR04 (mide la distancia al arroz → nivel)
  • Sensor de humedad y temperatura DHT22 (o DHT11, menos preciso)
  • Servomotor MG996R (abre la compuerta) o motor a pasos 28BYJ-48 con driver ULN2003 si usas tornillo sinfín
  • Resistencias de 1 kΩ y 2 kΩ (divisor de voltaje para el pin ECHO)
  • Resistencia de 10 kΩ (pull-up del DHT22, si tu módulo no la trae)
  • Fuente de 5 V / 2 A para el servo (no alimentes el servo desde el ESP32)
  • Contenedor tipo dispensador con compuerta inferior, protoboard y cables dupont

4 · Configurar Blynk

1Crea una cuenta en blynk.cloud.

2Ve a Developer Zone → My Templates → New Template. Nombre: Dispensador de Arroz, Hardware: ESP32, Conexión: WiFi.

3En Datastreams crea estos pines virtuales:

4En Events crea arroz_bajo y humedad_alta y activa las notificaciones para recibir alertas en el celular.

5(Opcional) En Web Dashboard y en la app móvil agrega Gauges para V2, V3, V4, un Slider para V0 y un Button (modo Push) para V1.

6Ve a Devices → New Device → From template. Copia el BLYNK_TEMPLATE_ID, BLYNK_TEMPLATE_NAME y el BLYNK_AUTH_TOKEN.

7Pega el Auth Token en Ajustes de esta página.

5 · Código para el ESP32

Arduino IDE: instala la placa esp32 by Espressif (Gestor de tarjetas) y las librerías Blynk (Volodymyr Shymanskyy), DHT sensor library (Adafruit) y ESP32Servo. Cambia tus datos de WiFi y Blynk, selecciona «ESP32 Dev Module» y sube el código.

// ===== Dispensador Inteligente de Arroz · ESP32 + Blynk =====
#define BLYNK_TEMPLATE_ID   "TMPLxxxxxxx"
#define BLYNK_TEMPLATE_NAME "Dispensador de Arroz"
#define BLYNK_AUTH_TOKEN    "TU_AUTH_TOKEN"
#define BLYNK_PRINT Serial

#include <WiFi.h>
#include <WiFiClient.h>
#include <BlynkSimpleEsp32.h>
#include <DHT.h>
#include <ESP32Servo.h>

char ssid[] = "TU_WIFI";
char pass[] = "TU_PASSWORD";

// ---- Pines ----
#define TRIG_PIN  5
#define ECHO_PIN  18
#define DHT_PIN   4
#define DHT_TYPE  DHT22
#define SERVO_PIN 13

// ---- Calibración (ver sección 6) ----
const float DIST_VACIO_CM  = 25.0;  // sensor -> fondo del depósito vacío
const float DIST_LLENO_CM  = 3.0;   // sensor -> arroz con depósito lleno
const float GRAMOS_POR_SEG = 20.0;  // gramos que caen por segundo con la compuerta abierta
const int   SERVO_CERRADO  = 0;
const int   SERVO_ABIERTO  = 90;
const float NIVEL_BAJO     = 15.0;  // % para alerta
const float HUMEDAD_ALTA   = 70.0;  // % para alerta

DHT dht(DHT_PIN, DHT_TYPE);
Servo compuerta;
BlynkTimer timer;

int   gramosPorcion = 70;
bool  dispensando   = false;
float servidoHoy    = 0;
bool  avisoNivel = false, avisoHumedad = false;

float medirDistancia() {
  digitalWrite(TRIG_PIN, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long dur = pulseIn(ECHO_PIN, HIGH, 30000);
  if (dur == 0) return -1;
  return dur * 0.0343 / 2.0;
}

void enviarSensores() {
  // Promedio de 5 lecturas del ultrasónico
  float suma = 0; int n = 0;
  for (int i = 0; i < 5; i++) {
    float d = medirDistancia();
    if (d > 0) { suma += d; n++; }
    delay(30);
  }
  if (n > 0) {
    float d = suma / n;
    float nivel = (DIST_VACIO_CM - d) / (DIST_VACIO_CM - DIST_LLENO_CM) * 100.0;
    nivel = constrain(nivel, 0, 100);
    Blynk.virtualWrite(V2, nivel);
    Blynk.virtualWrite(V6, d);
    if (nivel < NIVEL_BAJO && !avisoNivel) {
      Blynk.logEvent("arroz_bajo", "Queda poco arroz en el dispensador");
      avisoNivel = true;
    }
    if (nivel > NIVEL_BAJO + 10) avisoNivel = false;
  }

  float h = dht.readHumidity();
  float t = dht.readTemperature();
  if (!isnan(h)) {
    Blynk.virtualWrite(V3, h);
    if (h > HUMEDAD_ALTA && !avisoHumedad) {
      Blynk.logEvent("humedad_alta", "Humedad alta en el dispensador: revisa el arroz");
      avisoHumedad = true;
    }
    if (h < HUMEDAD_ALTA - 5) avisoHumedad = false;
  }
  if (!isnan(t)) Blynk.virtualWrite(V4, t);
}

void cerrarCompuerta() {
  compuerta.write(SERVO_CERRADO);
  dispensando = false;
  servidoHoy += gramosPorcion;
  Blynk.virtualWrite(V5, servidoHoy);
  Blynk.virtualWrite(V1, 0);
}

BLYNK_CONNECTED() { Blynk.syncVirtual(V0, V5); }

BLYNK_WRITE(V0) { gramosPorcion = param.asInt(); }
BLYNK_WRITE(V5) { servidoHoy = param.asFloat(); }

BLYNK_WRITE(V1) {
  if (param.asInt() == 1 && !dispensando && gramosPorcion > 0) {
    dispensando = true;
    unsigned long ms = (unsigned long)(gramosPorcion / GRAMOS_POR_SEG * 1000.0);
    compuerta.write(SERVO_ABIERTO);
    timer.setTimeout(ms, cerrarCompuerta);
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  dht.begin();
  compuerta.attach(SERVO_PIN);
  compuerta.write(SERVO_CERRADO);
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
  timer.setInterval(5000L, enviarSensores);
}

void loop() {
  Blynk.run();
  timer.run();
}

Para reiniciar «Servido hoy» cada día, en Blynk crea una Automation diaria a las 00:00 que escriba 0 en V5.

6 · Calibración

Nivel (ultrasónico)

  1. Con el depósito vacío, abre el Monitor Serie o mira V6 en Blynk: anota la distancia → DIST_VACIO_CM.
  2. Llénalo por completo y anota de nuevo → DIST_LLENO_CM.
  3. En Ajustes de la página escribe la capacidad del depósito en kg para estimar los días que alcanza.

Gramos dispensados

  1. Pon un recipiente sobre una báscula de cocina y tárala.
  2. Escribe 200 en V0 y dispensa. Pesa lo que cayó.
  3. Nuevo valor: GRAMOS_POR_SEG = 20 × (gramos reales ÷ 200). Repite 2 o 3 veces y promedia.
  4. Si la compuerta no abre lo suficiente, ajusta SERVO_ABIERTO (60–120).
7 · Limpieza y mantenimiento
  • Cada que se vacíe el depósito: limpia con un trapo seco; si lavas con agua, deja secar 24 h antes de rellenar.
  • Limpia el polvo de arroz de la compuerta cada mes para que no se atasque.
  • Sopla suavemente el HC-SR04 y el DHT22 si tienen polvo (lecturas raras = sensor sucio).
  • Cambia o reactiva el desecante cada 1–2 meses.
  • Nunca mojes el ESP32 ni los sensores.
8 · Solución de problemas
ProblemaSolución
La página dice «Modo demo»Revisa el token en Ajustes. Abre la página desde el archivo HTML o un hosting, no desde la vista previa.
«Dispositivo desconectado»El ESP32 no está en línea: revisa WiFi (solo 2.4 GHz), alimentación y el token en el código.
Nivel en 0 % o saltandoRevisa el divisor de voltaje del ECHO y que el sensor apunte recto hacia abajo.
Humedad «nan» o vacíaRevisa la resistencia de 10 kΩ del DHT22 y el pin GPIO 4.
El ESP32 se reinicia al dispensarEl servo necesita fuente externa de 5 V con GND común.
Sirve de más o de menosRecalibra GRAMOS_POR_SEG.
